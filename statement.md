# Project Statement

## 1. Problem Statement

      Educational institutions  frequently find it difficult to record, compute and review student grades efficiently. Faculty require a clean tool to easily record marks, compute GPAs and prevent incorrect inputs.

## 2. Scope of the project

      This project is a text based program built in Python. This program lets a user add student names, enter marksfor different subjects, calculate individual averages, and save all data records into a text file so nothing is lost when the program is closed.

## 3. Target users

     * Scoll teachers
     * College professors
     * Academic staff members

## 4. Main features

     * Creating new student enteries along there unique ID and Name.
     * Typing in marks for different subject(0 to 100).
     * viewing the class report with calculated averages.
     * Saving data automatically to a text file.
