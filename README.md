# Student Grade Evaluation and Performance Analytics System

## 1. Project overview

      This is a Python program created which helps faculty manage student profiles and record their grades. 
      The program project is split into 5 different Python files to keep the code clean, organised and easy to understand.

## 2. Features

      *  Add Students : Save student's Name and ID number.
      *  Add Marks : Record scores for different subjects.
      *  View Report : Shows individual average and overall class average.
      *  Save Data : Saves all information into text file called 'students.txt'.
      *  Erorr handling : Stops the program from crashing if invalid input is given.

## 3. Run the program

      1. Install Python
      2. Open Terminal or command prompt inside this project folder.
      3. Type command 'python main.py'
